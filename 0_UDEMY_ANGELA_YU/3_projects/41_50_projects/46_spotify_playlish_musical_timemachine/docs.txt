Step 2 - Youtube Music - Re-use your Browser's Requests to Authenticate
Authentication with ytmusicapi
YouTube Music doesn't have a simple API key. Instead, the ytmusicapi library works by borrowing your browser's login session (https://github.com/sigma67/ytmusicapi).

When you're logged into YouTube Music in your browser, your browser sends cookies and authentication headers with every request. We copy those request headers and let ytmusicapi turn them into a browser.json file for us.

The playlists you create will appear on whichever Google account you were logged into when you copied the headers.

**Note:** Browser cookies expire after a while. If authentication stops working after some time, you can just repeat these steps to get a fresh browser.json.

Basic Setup
1. You need a Google account. Any Google account works.

2. import and install the ytmusicapi library in your main.py.

3. Install the Firefox browser (if you don't have it already). Unfortunately, using Chrome will be a pain.

Copy the request headers in Firefox
Now let's create the `browser.json` file using the ytmusicapi library. This will involve some manual steps!

Use the Firefox browser for this step, because Firefox can copy the request headers directly.

1. Open Firefox and go to https://music.youtube.com. Make sure you are logged in to your Google account.

2. Open the browser Developer Tools:

- Mac: press Cmd + Option + I

- Windows/Linux: press Ctrl + Shift + I


3. Click the **Network** tab at the top of Developer Tools. In the Network tab's filter box, type `browse`. Refresh the page if you don't see any requests at all. Right click and Copy Value -> Copy Request Headers.

This copies the raw request headers, including the cookies from your logged-in browser session.


Look for a request named `browse?...` to `music.youtube.com`. It should be a normal successful request, not an ad or analytics request.

Paste the headers into your Terminal

Open your terminal and change directory (cd) to your project's folder.

Windows or Linux users:

You can just use this command:

ytmusicapi browser

Then ytmusicapi will prompt you to paste the request headers. Paste the headers you copied from Firefox. Then finish the input with Ctrl + D (or Ctrl + Z - whatever ytmusicapi tell you). Then hit Enter

If successful, ytmusicapi will create a browser.json file in your project folder. I found it quite handy to use the Terminal that's built into PyCharm:

Troubleshooting

If you see an error about missing headers:

   - Make sure you are logged in to YouTube Music (not just youtube.com).

   - Make sure you used Firefox and copied Copy Request Headers.

   - Make sure you chose a `browse?...` request from `music.youtube.com`.

   - Try clicking "Home" or "Library" again and copy a different `browse?...` request.

   - On Mac, do not paste the long headers directly into the default Terminal app (the headers will truncate and cmd + D will not do anything. Copy the headers into your clipboard and then use pbpaste | ytmusicapi browser.

Verify ytmusicapi works
4. Once you have `browser.json` in your project folder, create a `YTMusic` instance in your code and verify it works.

Create the instance with: 

yt = YTMusic("browser.json")
playlists = yt.get_library_playlists()
print(f"Found {len(playlists)} playlists in your library.")
You should see a list of your existing YouTube Music playlists printed to the console.
